# ShopSphere Frontend — Create React App

Modern frontend-only e-commerce UI for the ShopSphere project.

## Run
```bash
npm install
npm start
```

Open http://localhost:3000

## Included
- Create React App
- React Router
- Axios service ready for Spring Boot
- Responsive modern e-commerce UI
- Home, Products, Product Details
- Cart and Wishlist
- Login/Register demo auth
- Checkout demo flow
- Profile and Orders
- Mock product data
- Reusable components and contexts

Backend integration is configured for production at `https://shopsphere-backend-ybp1.onrender.com/api`.
